# Grades 2–3: Kids Coding Junior

A gentler first track for children aged 7–9: unplugged games and Scratch first,
then a short, friendly first look at Python. It leads into
[Grades 4–6](../grade-4-6/) Level 1 (Introductory).

> **Status:** All three levels are written and ready to teach, and they are on
> the [website](https://rrahimi-uci.github.io/kids-coding-curriculum/grade-2-3/).
> The scope and sequence is in [SYLLABUS.md](SYLLABUS.md).

| Level | Folder | Weeks | You will build | Final project |
|---|---|---|---|---|
| 1 · Little Robots | [1-little-robots/](1-little-robots/) | 10 + 2 buffers | Unplugged robot games and Scratch animations | My Animated Greeting Card |
| 2 · Game Makers | [2-game-makers/](2-game-makers/) | 10 + 2 buffers | Scratch games with score, random and win/lose | My First Arcade Game |
| 3 · Bridge to Python | [3-bridge-to-python/](3-bridge-to-python/) | 10 + 2 buffers | Pattern art, data and AI unplugged, first Python turtle | My Big Build |

Sessions are 45 minutes in Level 1 and 45–60 minutes in Levels 2–3, once a week,
taught at home by a parent. Student pages are picture-first and read aloud by
the parent; there are no quizzes, only show-me checklists.

Each level folder has the same layout as the Grades 4–6 levels
(`exercises/`, `project/`, `teaching-material/`); see
[1-little-robots/README.md](1-little-robots/README.md) to start. Build a level's
PDFs with `make pdf LEVEL=j1` (`j2`, `j3`) and a solution-free student copy with
`make student-bundle LEVEL=j1`. Which levels exist, and whether they are
`planned` or `active`, is set in [curriculum.json](../curriculum.json).
