## Hint 1: Where to look
Look at the two orange repeat blocks. Is one inside the other, or is one under the other?

## Hint 2: Try this
A block under a repeat runs only once, after the repeat is finished. A block inside a repeat runs every time. Which part should happen 6 times: only the turn, or the square and the turn?

## Hint 3: Almost there
Move the repeat ____ so it sits inside the repeat ____, above the turn. Then each time round the cat draws a square and turns.
