## Hint 1: Where to look
Look near the top for two lines marked `CHANGE ME`. One sets the color, one sets the pen size.

## Hint 2: Try this
A color name sits between two quote marks, like `"blue"`. Change only the word between the quote marks. The pen size is a number: bigger means thicker.

## Hint 3: Almost there
Make the lines say `t.color("____")` with a color name in the blank, and `t.pensize(____)` with a number like 5.
