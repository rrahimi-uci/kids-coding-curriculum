# Exercise 8.1 - Color My Square

**Goal:** change the color and the pen size of a square.
**Tool:** Thonny. **Work with a partner:** Driver and Helper.

## Steps

1. Click **Load**. Open `starter.py` in the `ex-color-square` folder.
2. Click **Run**. The square is black and thin.
3. Find `t.color("black")`. Change `black` to a color you like: `blue`, `orange`, `purple`, `green` or `gold`. Keep the quote marks!
4. Click **Save**, then **Run**.
5. Find `t.pensize(1)`. Change `1` to `5`.
6. Click **Save**, then **Run**.

## What you should see

The same square, but in your color, with thick lines. The turtle is
your color too.

Red text with `bad color string`? Check the spelling of your color.

## Checklist

- [ ] My square has a new color.
- [ ] My lines are thick.
- [ ] I changed one thing at a time and pressed Run each time.

**Extra:** try pen size `10`, then `20`. Which do you like best?
