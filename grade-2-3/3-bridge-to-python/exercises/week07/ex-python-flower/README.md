# Exercise 7.3 - Python Flower

**Goal:** make the week 1 flower in Python: a repeat inside a repeat.
**Tool:** Thonny. **Work with a partner:** Driver and Helper.

## Steps

1. Click **Load**. Open `starter.py` in the `ex-python-flower` folder.
2. Click **Run**. The turtle draws 2 squares.
3. Find the inner repeat: `for side in range(4):`. It draws one square.
4. Find the outer repeat: `for i in range(2):`. It says how many squares.
5. Change the `2` in the outer repeat to `6`.
6. Click **Save**, then **Run**.

## What you should see

Six black squares that all meet in the middle, like a flower with six
petals. The turtle ends in the middle, looking the same way as at the start.

## Checklist

- [ ] I can point to the inner repeat and the outer repeat.
- [ ] I changed 2 to 6.
- [ ] I see a flower of six squares.

**Extra:** change `6` to `4` and `60` to `90`. Now it is a window!
