# Junior Level 3 — Bridge to Python

For children in Grade 3 (ages 8–9) who finished Junior Level 2: pattern art with nested repeats, planning in parts, a family survey with bar graphs, an unplugged lesson on how computers learn, then a first look at Python turtle in Thonny. Ten 60-minute sessions, once a week,
taught at home by a parent, plus two optional buffer sessions.

**Final project:** *My Big Build*.

## Start here (for the grown-up)

1. Read the **Teacher Guide** (`teaching-material/teacher-guide.tex`): setup, the 60-minute
   session, roles, assessment and the 10-week plan.
2. Print for each child: **My Coding Book** (`student-workbook.tex`), the **Play-at-Home Cards**
   (`homework.tex`), the **Progress Tracker** and the **Cheat Sheet** (`extras/`), and the
   **Assessments** booklet for the week 1, 5 and 10 show-me checklists.
3. Before each session, read that week's plan in **Lesson Plans** (about 10 minutes).

Build the PDFs with `make pdf LEVEL=j3` (standard and dyslexia-friendly editions), or a
solution-free copy of the exercise folders with `make student-bundle LEVEL=j3`.

## What is in this folder

| Folder | Contents |
|---|---|
| `teaching-material/` | Teacher Guide, Lesson Plans, My Coding Book, Play-at-Home Cards, Answer Key, Assessments, and `extras/` (cheat sheet, word book, progress tracker, notes for families, certificate) |
| `exercises/weekNN/` | One folder per computer activity: steps, three hints, and a teacher-only reference |
| `project/` | The *My Big Build* brief and its teacher guide, plus the Python postcard starter and tested reference |

The week-by-week plan and goals are in [the Grades 2–3 syllabus](../SYLLABUS.md).
