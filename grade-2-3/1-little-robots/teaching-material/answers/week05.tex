\section{Lesson questions}
\begin{answer}[Exit question]
Three times. The repeat says 3, so the steps inside it (play sound Meow until done) run three times.
\end{answer}

\begin{answer}[Reflection]
Any number of colored stars is fine: it shows how many relay legs the child finished. For \enquote{Which bug was the trickiest?} any leg with a reason is a good answer (\enquote{Leg 2, because the blocks all looked right}). Note proud moments on the show-me checklist.
\end{answer}

\section{Workbook exercises}
\begin{answer}[Exercise 5.1: Arrow Maze]
The robot starts facing up and has to go around the tree. The shortest program uses six cards:
FORWARD, TURN RIGHT, FORWARD, FORWARD, TURN RIGHT, FORWARD.
(The robot steps into the middle row, turns to face the star's side, walks two squares, turns to face down, and steps onto the star.)

A longer program that goes along the top row is also right: FORWARD, FORWARD, TURN RIGHT, FORWARD, FORWARD, TURN RIGHT, FORWARD, FORWARD. Any program that never lands on the tree and ends on the star is right. Check by moving a finger on the grid one card at a time, turning the finger on the spot for each TURN.
\end{answer}

\begin{answer}[Exercise 5.2: Bug-Hunt Relay]
\textbf{Leg 1, The Quiet Cat.} The bug: \enquote{play sound Meow until done} is not snapped on, so it never runs. The cat says \enquote{Hi!} and stays quiet. Fix: drag the sound block until it clicks on under the say block. \textbf{You should see and hear:} \enquote{Hi!} for 2 seconds, then a meow.

\textbf{Leg 2, Bye Before Hi.} The bug: the two say blocks are in the wrong order, so the cat says \enquote{Bye!} first. Fix: drag the bottom block (\enquote{say Hi!}) up and let go right under \enquote{when green flag clicked}, so it clicks in above \enquote{say Bye!}. \textbf{You should see:} \enquote{Hi!} for 2 seconds, then \enquote{Bye!} for 2 seconds.

\textbf{Leg 3, Too Many Meows.} The bug: the repeat says 10, so the cat meows ten times. Fix: change 10 to 3. \textbf{You should hear:} exactly three meows, one after the other.

\textbf{What to look for:} \tickbox{} the child tests first (clicks the flag) \quad \tickbox{} says what was wrong \quad \tickbox{} changes one thing \quad \tickbox{} tests again.
\end{answer}

\begin{answer}[Exercise 5.3: My Best Show]
Many shows are right. With the example script, the cat says \enquote{Watch me!}, then walks a little to the right four times, changing costume each time with a 1-second pause, then says \enquote{Ta-da!}.

\textbf{What to look for:} \tickbox{} the script starts with \enquote{when green flag clicked} \quad \tickbox{} it has a repeat with at least one block inside \quad \tickbox{} all blocks are clicked together \quad \tickbox{} the child can say what it does, for example \enquote{My cat says watch me, then walks four times and says ta-da.}
\end{answer}

\section{Play-at-home card}
\begin{answer}[Arrow maze at home]
Any maze works. The robot should land on the goal square without stepping on the cushion. If it does not, the child finds the card where the robot went wrong and changes only that one.
\end{answer}

\begin{answer}[Spot the bug]
The child does the cards and stops where the path goes wrong (onto the cushion, off the squares, or away from the toy). That card is the bug. Any sensible fix that reaches the goal is right.
\end{answer}
