# Teacher reference: Exercise 2.1 - Hello Cat
> TEACHER ONLY. Keep this file away from students. It is not published on the website.

**Level and week:** Junior Level 1, Week 2 (Meet Scratch)  **Kind:** Scratch (offline app)  **Time:** about 8 minutes
**Big idea:** Blocks snap together into a script that runs from top to bottom when the green flag is clicked.

## The finished project
Setup: File > New. Keep the cat.

Sprite: Sprite1 (the cat)
- when green flag clicked
- say Hi! for 2 seconds
- play sound Meow until done
- move 50 steps

## What you should see
- After the green flag: a speech bubble "Hi!" for 2 seconds, then a meow, then the cat moves a little to the right.
- Each new click moves the cat a little further. Dragging it back on the stage is the right fix.

## Talking points
- Blocks are like puzzle pieces: they click together and run top to bottom.
- The green flag starts the show, like the paper flag in the puppet show.
- A sprite is a character; the stage is where it acts.

## Common mistakes and quick fixes
- Block let go too early: it is near the script but not on it. Drag it until the gray shadow shows.
- Clicked a block instead of the flag: that runs only part of it. Start with the green flag.
- Cat walked off the edge: drag it back to the middle.
- Real name typed in the bubble: change it to a nickname.

## Check-off list
- [ ] The script starts with "when green flag clicked": the yellow hat block is on top.
- [ ] All four blocks are snapped together: dragging the top block moves the whole script.
- [ ] The cat talks, meows and moves after the flag: watch one run.
