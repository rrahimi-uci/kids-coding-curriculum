# Teacher reference: Exercise 2.2 - The Stuck Cat (bug hunt)
> TEACHER ONLY. Keep this file away from students. It is not published on the website.

**Level and week:** Junior Level 1, Week 2 (Meet Scratch)  **Kind:** Scratch (offline app), bug hunt  **Time:** about 6 minutes
**Big idea:** Only blocks that are snapped on are part of the script; a loose block never runs.

## The finished project
Sprite: Sprite1 (the cat), after the fix
- when green flag clicked
- say Hi! for 2 seconds
- play sound Meow until done
- move 50 steps

## What you should see
- With the bug: the cat says "Hi!" and meows, but stays where it is.
- After the fix: the cat says "Hi!", meows and moves a little to the right.

## Bug-hunt answer
The bug is the loose "move 50 steps" block. It is not touching the script, so the green flag does not run it. Fix: drag it until it clicks on under "play sound Meow until done".

## Talking points
- Link to the puppet show: the card pushed away from the line was not part of the show.
- Testing means clicking the flag and watching closely: what happened, and what did not happen?

## Common mistakes and quick fixes
- The child rebuilds the whole script instead of moving one block: praise that it works, then show that dragging one block is enough.
- The block snaps on at the top instead of the bottom: the order changes (the cat moves first). Ask the child to read the script top to bottom.

## Check-off list
- [ ] The child can point to the loose block: they say which block did not run.
- [ ] The block is snapped on: dragging the top block moves all four.
- [ ] The cat moves after the fix: watch one run.
