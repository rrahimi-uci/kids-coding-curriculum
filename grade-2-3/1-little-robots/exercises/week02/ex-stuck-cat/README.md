# Exercise 2.2 – The Stuck Cat (bug hunt)

**Goal:** find the block that does not run, and fix it.
**Tool:** Scratch app. **Work with a partner:** Driver and Helper.

## Build steps

1. Build Kai's script below. Leave **move 50 steps** a little way below the others, not touching.
2. Click the green flag. What does the cat do? What does it not do?
3. Find the block that did not run.
4. Drag it up until it clicks on. Click the flag again.

## The script in words (with the bug)

- when green flag clicked
- say Hi! for 2 seconds
- play sound Meow until done
- (not snapped on) move 50 steps

## Expected behavior

With the bug, the cat says "Hi!" and meows but does not move. After the fix,
the cat says "Hi!", meows and moves.

## Checklist

- [ ] I found the block that was not snapped on.
- [ ] I snapped it on.
- [ ] Now the cat moves too.
