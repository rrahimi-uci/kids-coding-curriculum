# Exercise 3.1 – Ready, Set, Go!

**Goal:** make the cat say Ready, Set, Go!, and use a wait so you can see every word.
**Tool:** Scratch app. **Work with a partner:** Driver and Helper.

## Build steps

1. Click **Events** (yellow). Drag in **when green flag clicked**.
2. Click **Looks** (purple). Snap on the plain **say Hello!** block, with no seconds. Type `Ready`.
3. Snap on two more plain **say** blocks. Type `Set` and `Go!`.
4. Click **Motion** (blue). Snap on **glide 1 secs to random position**.
5. Test: click the green flag. Look: did you see Ready and Set?
6. Click **Control** (orange). Snap **wait 1 seconds** under Ready. Test again.
7. Is Set still too fast? Fix it the same way.

## The script in words

- when green flag clicked
- say Ready
- say Set
- say Go!
- glide 1 secs to random position
- (you add wait blocks to fix the bug)

## Expected behavior

At first the cat only says "Go!" and glides away. After your fix, the cat says
"Ready", then "Set", then "Go!", one word at a time, and glides to a surprise place.

## Checklist

- [ ] I used the say block with no seconds.
- [ ] I tested after each change.
- [ ] I can see Ready, Set and Go!
