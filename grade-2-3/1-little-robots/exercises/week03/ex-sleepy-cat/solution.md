# Teacher reference: Exercise 3.2 - The Sleepy Cat (bug hunt)
> TEACHER ONLY. Keep this file away from students. It is not published on the website.

**Level and week:** Junior Level 1, Week 3 (Bugs Are Clues)  **Kind:** Scratch (offline app), bug hunt  **Time:** about 6 minutes
**Big idea:** Steps run in order from top to bottom; a step in the wrong place is a bug we can find by testing and fix by moving one block.

## The finished project
Sprite: Sprite1 (the cat), after the fix
- when green flag clicked
- think Zzz for 2 seconds
- say Good morning! for 2 seconds
- move 50 steps

## What you should see
- With the bug: the cat says "Good morning!" for 2 seconds, moves a little to the right, then thinks "Zzz" (a thought bubble) for 2 seconds.
- After the fix: a "Zzz" thought bubble for 2 seconds, then "Good morning!" for 2 seconds, then the cat moves a little to the right.

## Bug-hunt answer
The bug is steps in the wrong order: "think Zzz for 2 seconds" is at the bottom but should be first. Fix: drag "think Zzz" (the bottom block, so nothing else comes with it) and drop it right under "when green flag clicked". Scratch inserts it there.

## Talking points
- Link to the warm-up robot that put its shoes on before its socks: same steps, wrong order.
- Test, look, change one thing: one drag fixes it, then test again.
- Kind words: the Helper says "I think I found a clue!", the Driver says "Thanks!"

## Common mistakes and quick fixes
- Dragged the say block from the middle: every block under it comes too. Drag the pieces back together and try the bottom block instead.
- Dropped the block above the hat block: it does not join. Drop it under the green flag block.
- Rebuilt the whole script: it works, so praise it, then show that one drag is enough.
- Each run moves the cat further: drag it back on the stage with the mouse.

## Check-off list
- [ ] The child tested first and said what went wrong: "it slept at the end".
- [ ] "think Zzz" is now the first block under the green flag: read it top to bottom.
- [ ] The cat sleeps, wakes and walks, in that order: watch one run.
