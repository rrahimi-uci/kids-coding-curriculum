# Junior Level 1 — Little Robots

For children in Grades 2–3 (ages 7–9) with no coding experience: robot games on
the floor first, then the free Scratch 3 offline app. Ten 45-minute sessions,
once a week, taught at home by a parent, plus two optional buffer sessions.

**Big ideas:** exact steps in order, repeat loops, starting code with the green
flag, a click or a key, fixing bugs, and planning a little story.
**Final project:** *My Animated Greeting Card*.

## Start here (for the grown-up)

1. Read the **Teacher Guide** (`teaching-material/teacher-guide.tex`) — setup, the
   45-minute session, Driver and Helper, and the 10-week plan.
2. Install the free **Scratch 3** app from the Mac App Store (no account) and
   plug in a mouse.
3. Print for each child: **My Robot Book** (`student-workbook.tex`), the
   **Play-at-Home Cards** (`homework.tex`), the **Progress Tracker** and the
   **Cheat Sheet** (`extras/`). Print the **Assessments** booklet once per child
   for the week 5 and week 10 show-me checklists.
4. Before each session, read that week's plan in **Lesson Plans** (about 10 minutes).

Build the PDFs with `make pdf LEVEL=j1` (standard and dyslexia-friendly editions),
or a solution-free copy of the exercise folders with `make student-bundle LEVEL=j1`.

## What is in this folder

| Folder | Contents |
|---|---|
| `teaching-material/` | Teacher Guide, Lesson Plans, My Robot Book, Play-at-Home Cards, Answer Key, Assessments, and `extras/` (cheat sheet, glossary, progress tracker, notes for families, certificate) |
| `exercises/weekNN/` | One folder per Scratch activity: build steps, three hints, and a teacher-only `solution.md` |
| `project/` | The *My Animated Greeting Card* brief and its teacher guide |

The week-by-week plan and goals are in [the Grades 2–3 syllabus](../SYLLABUS.md).
