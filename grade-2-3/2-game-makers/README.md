# Junior Level 2 — Game Makers

For children in Grades 2–3 (ages 8–9) who finished Junior Level 1: Scratch games: forever loops, if-touching, score, random numbers, messages, My Blocks, and start, win and game-over screens. Ten 60-minute sessions, once a week,
taught at home by a parent, plus two optional buffer sessions.

**Final project:** *My First Arcade Game*.

## Start here (for the grown-up)

1. Read the **Teacher Guide** (`teaching-material/teacher-guide.tex`): setup, the 60-minute
   session, roles, assessment and the 10-week plan.
2. Print for each child: **My Game Book** (`student-workbook.tex`), the **Play-at-Home Cards**
   (`homework.tex`), the **Progress Tracker** and the **Cheat Sheet** (`extras/`), and the
   **Assessments** booklet for the week 1, 5 and 10 show-me checklists.
3. Before each session, read that week's plan in **Lesson Plans** (about 10 minutes).

Build the PDFs with `make pdf LEVEL=j2` (standard and dyslexia-friendly editions), or a
solution-free copy of the exercise folders with `make student-bundle LEVEL=j2`.

## What is in this folder

| Folder | Contents |
|---|---|
| `teaching-material/` | Teacher Guide, Lesson Plans, My Game Book, Play-at-Home Cards, Answer Key, Assessments, and `extras/` (cheat sheet, word book, progress tracker, notes for families, certificate) |
| `exercises/weekNN/` | One folder per computer activity: steps, three hints, and a teacher-only reference |
| `project/` | The *My First Arcade Game* brief and its teacher guide |

The week-by-week plan and goals are in [the Grades 2–3 syllabus](../SYLLABUS.md).
