# Exercise 1.1 – Bounce Cat

**Goal:** make the cat run from side to side, forever.
**Tool:** Scratch app. **Work with a partner:** Driver and Helper.

## Build steps

1. Click **Events** (yellow). Drag in **when green flag clicked**.
2. Click **Motion** (blue). Snap on **point in direction 90**.
3. Snap on **set rotation style left-right** (blue Motion).
4. Click **Control** (orange). Snap on **forever**.
5. Put **move 10 steps** (blue Motion) inside the forever.
6. Put **if on edge, bounce** (blue Motion) inside too, under the move.
7. Click the green flag. Watch. Then click the red stop sign.

## The script in words

- when green flag clicked
- point in direction 90
- set rotation style left-right
- forever
  - move 10 steps
  - if on edge, bounce

## Expected behavior

The cat runs to one edge, turns around, and runs back. It keeps going until
you click the red stop sign. It faces the way it walks and never goes upside down.

## Checklist

- [ ] Move and bounce are inside the forever.
- [ ] The cat bounces from side to side.
- [ ] I stopped it with the red stop sign.
