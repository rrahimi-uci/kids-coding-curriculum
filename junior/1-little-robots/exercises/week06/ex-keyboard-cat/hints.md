## Hint 1: Where to look
Key blocks live in yellow **Events**. Look for the block that says "when space key pressed".

## Hint 2: Try this
Each key block starts its own script. The little arrow in the block lets you pick a different key. If a key does nothing, click the stage once and try again.

## Hint 3: Almost there
Script 1: "when ____ key pressed", then move, then next costume. Script 2: "when space key pressed", then a repeat with a ____ block inside.
