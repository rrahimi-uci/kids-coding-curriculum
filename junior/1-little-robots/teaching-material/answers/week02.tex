\section{Lesson questions}
\begin{answer}[Exit question]
No. A block that is not snapped on is not part of the script, so clicking the green flag does not run it.
\end{answer}

\begin{answer}[Reflection]
Any drawing of a sprite is right. \enquote{A sprite is a character that can act, like the cat} (or \enquote{the cat}, \enquote{the thing that moves}) all show understanding.
\end{answer}

\section{Workbook exercises}
\begin{answer}[Exercise 2.1: Hello Cat]
\textbf{What you should see:} after the green flag, the cat says \enquote{Hi!} in a speech bubble for 2 seconds, then meows, then moves a little to the right. Each new click moves it further; dragging it back is fine.

\textbf{What to look for:} \tickbox{} the script starts with \enquote{when green flag clicked} \quad \tickbox{} all four blocks clicked together \quad \tickbox{} the child starts it with the flag.
\end{answer}

\begin{answer}[Exercise 2.2: The Stuck Cat]
The circled block is \enquote{move 50 steps}: it sits apart from the script, so it never runs. After dragging it up until it clicks on, the cat says hi, meows and moves.
\end{answer}

\section{Play-at-home card}
\begin{answer}[Puppet show at home]
Swapping two cards changes the order of the show: for example, the toy moves before it says hello. Any sensible answer about \enquote{it does them in a different order} is right.
\end{answer}

\begin{answer}[If you have Scratch at home]
Look for the same script as Exercise 2.1, with new words (a nickname, never a real name) or a different sound chosen from the dropdown.
\end{answer}
