# Exercise 6.1 - Hello, Turtle!

**Goal:** run your first Python program, then change one number.
**Tool:** Thonny. **Work with a partner:** Driver and Helper.

## Steps

1. In Thonny, click **Load**. Open `starter.py` in the `ex-hello-turtle` folder.
2. Click the green **Run** button. Watch the turtle window.
3. Find the line `t.forward(50)`. It is like **move 50 steps** in Scratch.
4. Change `50` to `150`. Keep the brackets!
5. Click **Save**, then **Run** again.

## What you should see

A white window with a small turtle. The turtle walks to the right and
draws one long black line. Then it makes a quarter turn and looks up.

If you see red text instead, read it with your grown-up. It tells you the
line to look at.

## Checklist

- [ ] I clicked Run and the turtle moved.
- [ ] I changed 50 to a bigger number.
- [ ] The line got longer.

**Extra:** try 250. Try 100. Which line is the longest?
