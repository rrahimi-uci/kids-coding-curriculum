# Exercise 8.3 - My Square Block (stretch)

**Goal:** use a Python block called `square`, like a Scratch My Block.
**Tool:** Thonny. **Work with a partner:** Driver and Helper.

## Steps

1. Click **Load**. Open `starter.py` in the `ex-square-block` folder.
2. Click **Run**. One blue square.
3. Find `def square():`. It is like **define square** in Scratch.
4. Find `square()` near the bottom. That line uses the block.
5. Find `for i in range(1):`. Change `1` to `4`.
6. Click **Save**, then **Run**.

## What you should see

Four blue squares that touch in the middle, like a window with four
panes. The turtle ends in the middle.

## Checklist

- [ ] I found the block called square.
- [ ] I changed 1 to 4.
- [ ] I see a window of four squares.

**Extra:** change `60` inside `def square():` to `100`. Run it. All four
squares get bigger at once!
