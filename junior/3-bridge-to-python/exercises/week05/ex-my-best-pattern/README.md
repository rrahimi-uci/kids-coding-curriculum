# Exercise 5.3 – My Best Pattern

**Goal:** plan a pattern in three parts, then build it with a repeat inside a repeat.
**Tool:** Scratch app with the Pen extension. **Work with a partner:** Driver and Helper.

## Build steps

1. Write your three parts in your book: get ready, the pattern, the ending.
2. Click **File**, then **New**. Add the **Pen** extension (bottom left). Drag the cat to the middle.
3. **Part 1.** From **Events** (yellow), drag in **when green flag clicked**. From **Pen** (green), add **erase all**, **set pen color to**, and **pen down**.
4. **Part 2.** From **Control** (orange), add a **repeat**. Put a second **repeat** inside it. Inside that one, add **move** and **turn** from **Motion** (blue). Test it.
5. **Part 3.** From **Looks** (purple), add a **say** block at the end. Test again.

## The script in words

One idea:

- when green flag clicked
- erase all, set pen color to purple, pen down
- repeat 6
  - repeat 4: move 50 steps, turn right 90 degrees
  - turn right 60 degrees (hexagon number from the turn card)
- say Ta-da! for 2 seconds

## Expected behavior

The cat draws a pattern of shapes, then says something.
