# Exercise 4.3 – The Stuck Dice (bug hunt)

**Goal:** Omar's cat should say a new number every 2 seconds. Find the bug and fix it.
**Tool:** Scratch app. **Work with a partner:** Driver and Helper.

## Build steps

1. Click **File**, then **New**.
2. Click **Variables** (orange-red). Make a variable called `roll`.
3. Build Omar's script as you see it, with the bug.
4. **Test:** click the green flag. Watch for a while.
5. **Look:** what should it do? What does it do?
6. **Change one thing.** Then test again.

## The script in words (with the bug)

- when green flag clicked (yellow Events)
- set roll to (pick random 1 to 10) (Variables and green Operators)
- forever (orange Control)
  - say (roll) for 1 seconds (purple Looks)
  - wait 1 seconds

## Expected behavior

After the fix, the cat says a new surprise number every 2 seconds.
Sometimes the same number comes twice. That is still random!

## Checklist

- [ ] I tested it and saw the bug.
- [ ] I found the block that rolls the die.
- [ ] After my fix, the cat says new numbers.
