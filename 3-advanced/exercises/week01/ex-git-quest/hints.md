## Hint 1: Where to look
Read the Level you are stuck on again, and check that Terminal is inside the `git-quest` folder. Type `pwd` to see where you are. The command `git status` also tells you what git is thinking right now.

## Hint 2: Try this
Git saves in two steps. First you choose what goes in the save, then you make the save point with a label. Use `git diff` to see what changed before you save. The cheat sheet at the bottom of the README lists every command you need.

## Hint 3: Almost there
To make a save point, type `git add ____` and then `git commit -m "____"`. Put your file name in the first blank and a message that says what changed in the second. To undo unsaved changes, look up `git restore ____`. Put the file name in the blank.
