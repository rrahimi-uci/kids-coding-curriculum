\subsection{Exercise 6.2: Bug Hunt 2, Lost Scores}
\pyfile{../excercises/week06/ex-bug-lost-items/solution.py}
\begin{answer}[Exercise 6.2: Lost Scores]
The buggy starter printed \texttt{Sorted: [10, 30, 40]} and \texttt{Original: [50]}. Three fixes: \texttt{remaining = list(scores)} (a copy, so the original is not emptied); \texttt{while len(remaining) > 0} (the last score was left behind); always \texttt{result.append(smallest)} (the duplicate 10 was skipped).
Accept \texttt{scores[:]} or \texttt{scores.copy()} for the copy, and \texttt{while remaining:} for the loop.
\end{answer}

\subsection{Exercise 6.3: Bug Hunt 3, Word Finder}
\pyfile{../excercises/week06/ex-bug-binary-search/solution.py}
\begin{answer}[Exercise 6.3: Word Finder]
\textbf{Trace table (buggy code):} \texttt{low} = 0, \texttt{high} = 3 (the buggy \texttt{len(words)}), \texttt{0 < 3} is true, \texttt{mid} = 1, \enquote{bee} is bigger than \enquote{ant}, so \texttt{high} = 0. Next check: \texttt{0 < 0} is false, so the loop stops and returns $-1$, although \enquote{ant} is still there at index 0: one item was left, but never checked.
The starter could not find \enquote{dragon}, \enquote{eagle} and others. Fixes: \texttt{high = len(words) - 1} and \texttt{while low <= high}. Fixing only the loop condition first gives \texttt{IndexError} for \enquote{zebra}; that is expected progress.
\end{answer}
