# Homework 8 - Loop Fixer

**Goal:** this program should draw a blue square and an orange star.
It has **2 loop bugs**. Find and fix them.

1. Open `starter.py` and press **Run** (F5). Watch carefully.
2. **Square bug:** count the sides. How many times does the loop repeat?
3. **Star bug:** the star is a straight line! Which line is NOT inside the loop?
   (Look at the spaces at the start of each line.)
4. Fix one bug, press **Run**, then fix the other.

**Done looks like:** a closed blue square and a closed orange 5-pointed star.

**Check your work:** open `check_my_work.py` and press **Run**.

**Challenge:** draw a 7-pointed star: 7 sides, turn 360 x 3 / 7, about 154.
