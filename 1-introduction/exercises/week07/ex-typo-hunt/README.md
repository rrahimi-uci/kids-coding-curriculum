# Exercise 7.3 - Typo Hunt

**Goal:** this program should draw a flag on a pole, but it has **4 typos**.
Find them and fix them.

1. Open `starter.py` in Thonny and press **Run** (F5).
2. Python stops at the first bug and shows a red message in the Shell.
   Read it like a detective:
   * the **line number** tells you where to look,
   * the **last line** says what Python did not understand.
3. Fix that one typo. Press **Run** again. Repeat until there is no red text.

**Clues:** Python is picky about capital letters, spelling, and names.
Compare each line with a line that already works.

**Done looks like:** no red error, the Shell says `Typo hunt: fixed!`, and the
turtle draws a pole with a flag at the top (4 lines).

**Check your work:** open `check_my_work.py` and press **Run**.

**Extra:** write down each bug you fixed and the line number. Which one was the
sneakiest?
