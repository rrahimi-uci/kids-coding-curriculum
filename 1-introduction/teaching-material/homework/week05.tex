\begin{core}[Starry Sky (Scratch, about 10 minutes)]
Make your own \enquote{star} block and fill the night sky.
\begin{enumerate}[leftmargin=1.4em,itemsep=1pt]
  \item Open Scratch and add the \menu{Pen} extension. Pick a dark backdrop (for example \textbf{Stars}, or paint the backdrop dark blue).
  \item \menu{My Blocks} $\rightarrow$ \menu{Make a Block}: name it \texttt{star}, add an input \texttt{size}, click \menu{OK}.
  \item Build both scripts. Drag \texttt{size} out of the define hat into the move block. For the pen color, click the color circle and set \textbf{Color 16, Saturation 72, Brightness 94} (yellow from the color-safe paint box).
  \item Click the flag. Save as \texttt{starry-sky}.
\end{enumerate}
\begin{center}
\begin{scratch}[scale=0.75]
\initmoreblocks{define \namemoreblocks{star \ovalmoreblocks{size}}}
\blockpen{pen down}
\blockrepeat{repeat \ovalnum{5}}{
  \blockmove{move \ovalmoreblocks{size} steps}
  \blockmove{turn \turnright{} \ovalnum{144} degrees}
}
\blockpen{pen up}
\end{scratch}
\hspace{0.5cm}
\begin{scratch}[scale=0.75]
\blockinit{when \greenflag clicked}
\blockpen{erase all}
\blockpen{set pen color to \pencolor{kcyellow}}
\blockpen{set pen size to \ovalnum{3}}
\blockpen{pen up}
\blocklook{hide}
\blockrepeat{repeat \ovalnum{10}}{
  \blockmove{go to \selectmenu{random position}}
  \blockmoreblocks{star \ovaloperator{pick random \ovalnum{10} to \ovalnum{60}}}
}
\end{scratch}
\end{center}
Why does the star block turn 144 degrees and not 72? (Hint: count how many times the pen goes all the way round.)
\answerlines{1}
\end{core}

\begin{creative}[Good night message]
Add a \textbf{Button} sprite (any sprite) that says \enquote{Click me for night time}. When it is clicked, it broadcasts a new message \texttt{night falls}. Give the cat a \enquote{when I receive night falls} script that says \enquote{Good night!}. Check that both blocks use exactly the same message.
\end{creative}

\begin{selfcheck}

  \item My stars can be seen clearly on the dark sky (I used a color from the paint box).
  \item (Creative) My broadcast and my \enquote{when I receive} use the same message.
