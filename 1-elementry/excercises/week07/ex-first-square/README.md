# Exercise 7.2 - My First Square

**Goal:** make the turtle draw a square.

1. Open `starter.py` in Thonny.
2. Finish the program so the turtle draws a square: 4 sides, all the same
   length, turning 90 degrees at each corner.
3. Press the green **Run** button to watch your turtle.

**Done looks like:** a closed square (the turtle ends where it started).

**Check your work:** open `check_my_work.py` and press **Run**.

**Extra:** change the colour with `t.color("#0072B2")` or make it bigger.
