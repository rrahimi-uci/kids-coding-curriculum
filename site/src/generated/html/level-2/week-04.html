The big idea: repeat until something changes

A for loop knows how many times it will go round. A while loop does not: it checks a condition at the top, and goes round again while the condition is True.

This prints 3, 2, 1, Go!. The line n = n - 1 is the change: without it, n stays 3, the check is always True, and the loop never ends. That is an infinite loop.

TipStuck in a loop?

Press the red Stop button in Thonny’s toolbar. Then ask two questions: What is checked? and What changes inside the loop, so the check can become False?

while True and break

Sometimes it is easier to loop “for ever” and jump out when you are done. break leaves the loop straight away. Inside a function, return leaves the loop and the function.

Keep asking until the answer is good

while True:
    answer = input("Type yes or no: ").lower()
    if answer == "yes" or answer == "no":
        break                       # good answer: leave the loop
    print("Please type yes or no.")
print("Thanks!")

Checking the player’s answer like this is called input validation. Games do it all the time, so a typo never crashes them. answer.isdigit() is True only if the answer is made of the digits 0–9: then int(answer) is safe.

A loop inside a loop: pixel art

A picture can be a list of strings: one string for each row, one letter for each pixel. The outer loop goes down the rows. The inner loop goes along one row, pixel by pixel.

for row in grid:            # outer loop: one row at a time
    for pixel in row:       # inner loop: one letter at a time
        print(pixel)
