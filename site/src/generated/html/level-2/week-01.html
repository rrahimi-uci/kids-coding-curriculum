Bug hunt: text plus a number

Try "5" + 5 in the Shell. Python shows a red error message. Always read it from the bottom line up:

TypeError: can only concatenate str (not "int") to str

“Concatenate” means “glue together”. Python can glue text to text, but not text to a number. This matters because input() always gives back text, even when you type a number. Turn it into a whole number with int():

level = int(input("Level? "))     # the player types 4
print(level + 1)                  # 5

f-strings: fill in the blanks

Put an f in front of the quotes, and Python fills every pair of curly brackets with a value. It works with any type, so you never have to worry about text plus a number.
