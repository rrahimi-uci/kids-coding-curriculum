The big idea: programs forget, files remember

When a program closes, all its variables are wiped. Your high score? Gone. A file is like a notebook in a drawer: it stays on the computer after the program closes, so next time the program can read it again.

Writing to a file

Save one score

with open("high_scores.txt", "a") as file:
    file.write("Ada,120\n")

  • open(name, mode) opens the file. with closes it again for you when the indented block ends.

  • \n means “new line”. Without it, everything ends up squashed on one line.

Mode Means Like a notebook…
"r" read Just read it. Crashes if the notebook is not there.
"a" append (add to the end) Write on the next empty line. Makes a new notebook if needed.
"w" write (replace) Rip out every page, then write. Careful: old data is gone!

Reading a file, line by line

Load the scores back

scores = []
with open("high_scores.txt", "r") as file:
    for line in file:
        line = line.strip()            # "Ada,120\n" -> "Ada,120"
        if line != "":                 # skip empty lines
            parts = line.split(",")    # "Ada,120"   -> ["Ada", "120"]
            scores.append([parts[0], int(parts[1])])
print(scores)                          # [['Ada', 120], ['Kai', 95]]

Everything you read from a file is text (a str), just like input(). Use int() to turn "120" into the number 120.

Bug hunt: the file is not there!

The very first time a game runs, there is no score file yet. Reading it gives:

FileNotFoundError: [Errno 2] No such file or directory: 'high_scores.txt'

Check the spelling of the name first. If the file really is new, catch the error with try and except:

try:
    with open("high_scores.txt", "r") as file:
        print(file.read())
except FileNotFoundError:
    print("No scores yet - you will be the first!")

try means “have a go”. except FileNotFoundError means “if the file is missing, do this instead of crashing”.

TipWhat should a game save?

A file stays on the computer, and anyone who uses the computer can open it. Save only what the program needs: nicknames, scores, words, drawings. Never save real names, addresses, schools, birthdays or passwords.
