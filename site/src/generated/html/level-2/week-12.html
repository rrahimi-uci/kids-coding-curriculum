How to explain your project

A great showcase pitch is short. Answer four questions, in this order:

  1. What is it? “This is Comet Catch. You catch comets with a rocket.”

  2. How does one part work? Pick one function, the loop, the list, the dictionary or the file. “Our next_x function gets the position and the direction and returns the new position, but never off the screen. We have a test for that.”

  3. One design decision. Why did you choose something? “The comets are circles and the rocks are squares, so you can tell them apart even without color.”

  4. What next? “Next we would add a slow mode for beginners.”

If something is not finished, that is normal. Show what works, then say what you would add next.

Exercise12.4: Looking ahead to Level 3

In Level 3 you will save your code with git save points (like save points in a video game), design your own classes (blueprints for game characters and objects), and build bigger projects. The example project is Maze Muncher: a maze game where a ghost hunts you down with a clever search algorithm.
