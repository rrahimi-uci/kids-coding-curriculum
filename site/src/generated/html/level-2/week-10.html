The big idea: build a skateboard first

If you want to build a car, you do not start with one perfect wheel. Nobody can ride a wheel! You build a skateboard first: tiny, but you can ride it. Then a scooter, a bike, a car. Every version works.

Your project works the same way. The core loop is your skateboard:

  • Arcade Game: a window, a player that moves with the keys, and a timer loop that keeps running (screen.ontimer).

  • Art Studio: a while loop that asks what to do (draw, save, load, quit) and does it.

No score, no title screen, no fancy colors yet. Those come later, and they are easy once the skeleton walks.

Pseudocode and flowcharts

Pseudocode is your program written in plain English, one step per line, before you write Python. A flowchart draws the same steps as shapes joined by arrows. Three shapes are all you need: ovals for start and end, rectangles for steps, and diamonds for yes/no questions. Here is the flowchart for a catching game:

The same plan as pseudocode:

set up the screen, the player and the keys
repeat every tick:
move every falling thing down
if a falling thing touches the player: add 1 to the score
if the game is over: save the high score and stop

Every line that does one job can become a function. “Move the player but not off the screen” becomes next_x(x, direction): the position and direction go in, the new position comes out. That is decomposition: breaking a big problem into small named parts.

Exercise10.3: Build the core loop (M2)

Make a folder for your team’s project and save your program as mygame.py (or mystudio.py). Never call it turtle.py! Build it in small steps and press F5 after each one. For an arcade game, the heart of the program is a loop that runs itself again:

the timer loop

def game_loop():
    if not state["running"]:
        return
    # TODO: move falling things, check for catches, add to the score
    screen.update()
    screen.ontimer(game_loop, 50)   # run again in 50 milliseconds

Exercise10.4: Partner code review

Swap seats with your partner (or another team). Run their program and read their code. Then write two stars and a wish: two things that are really good, and one kind idea. Be specific: “the name next_x tells me exactly what it does” helps more than “nice”.
