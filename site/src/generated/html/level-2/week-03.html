The big idea: a row of lockers

A list is like a row of lockers. Each locker has a number painted on it, called its index. The first locker is number 0.

Making and using a list

backpack = ["torch", "rope", "map"]
backpack.append("apple")    # adds to the END of the list
print(len(backpack))        # 4   how many items
print(backpack[0])          # torch   the first item
print(backpack[-1])         # apple   -1 means the last item

With 4 items, the index numbers are 0, 1, 2 and 3. Asking for backpack[4] crashes with IndexError: list index out of range. This is called an off-by-one bug.

Two ways to loop over a list

Visit every item Visit every index number
for item in backpack: for i in range(len(backpack)):
    print(item)     print(i, backpack[i])
Use it when you only need the items. Use it when you also need the position number.

Colors for everyone

Some people see colors differently, often red and green. These eight Okabe-Ito colors stay different for almost everyone. Use them, and always add a label, number or shape too, so color is never the only clue.
