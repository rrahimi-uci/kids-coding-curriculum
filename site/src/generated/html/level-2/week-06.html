The big idea: debug like a detective

Every programmer writes bugs. Good programmers find them with a strategy: they collect clues, change one thing and test again.

Tool 1: read the traceback from the bottom up

When a program crashes, Thonny shows a red traceback like this one:

Traceback (most recent call last):
  File "starter.py", line 24, in <module>
  File "starter.py", line 17, in make_card
  File "starter.py", line 10, in card_line
    return label + ": " + value
TypeError: can only concatenate str (not "int") to str

  1. WHAT went wrong: the last line. Here: a TypeError, text + number.

  2. WHERE: the File line just above it. Here: line 10, in the function card_line.

  3. HOW it got there: the lines further up. The main program (line 24) called make_card, which called card_line.

In Thonny you can click the blue link to jump straight to that line.

Error name It usually means…
TypeError two types that do not go together, like text + number
IndexError a list index that does not exist (remember: the last index is len - 1)
KeyError a dictionary key that does not exist (check the spelling)
NameError a variable name Python does not know (typo, or missing quotes)
ValueError the right type but a bad value, like int("banana")

Tool 2: print-debugging

Not sure what is inside a variable? Ask Python! Add a print() line, run, look, then remove it.

print("best is", best, "length", len(best))

Tool 3: the rubber duck

Explain your code, line by line, out loud, to a partner, a toy or a rubber duck. Say what each line should do. Very often you hear yourself say the bug before you reach the end. This is the best tool for bugs that do not crash.

Tool 4: the trace table

Follow the code with a pencil, like a very slow computer. Write a column for each variable and a row each time round the loop. When the table shows a value you did not expect, you have found the bug.

TipBugs are normal

If you are stuck, you are not bad at coding: you are in the middle of learning. Say “I can’t fix this yet”, pick a tool and try one thing.
