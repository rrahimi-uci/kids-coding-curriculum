TipThe secret of easy tests

Put the rules of your program (scores, moving, touching, saving) in small functions that do not use turtle. They take values in and return an answer, so they are easy to test. Keep the drawing in other functions.

Support and extension

Start from the template and change it step by step. Aim first for M2 (the core loop) and two tests; your teacher can be your navigator. A small project that works and that you can explain is a great project. Put your rules in their own file (like starcatcher_logic.py in the reference game) and import it. Add levels, a start menu, a top-5 high-score table, or let players choose their own keys. Write a test for your file functions.

When you are stuck

  1. Read the error message: start with the last line.

  2. Print the values: print("x is", x).

  3. Explain your code line by line to your partner or a rubber duck.

  4. Make the problem smaller: test one function on its own.

  5. Check the cheat sheet and the starter/README.md.

  6. Ask your teacher: say what you expected and what happened instead.
