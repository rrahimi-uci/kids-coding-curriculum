The big idea: let the computer check your code

Checking a game by hand is slow: run it, play, look at the score… again and again. A test is a tiny function that checks another function for you, in less than a second. It uses the word assert, which means “I am sure this is true”.

A test for clamp(), which keeps a number between two limits

from clamp_tools import clamp

def test_too_big_comes_down_to_high():
    assert clamp(99, 0, 10) == 10, "99 is too big, so it should become 10"

A test has three parts: call the function with values you choose, say what you expect with ==, and add a message for when it goes wrong. The function’s name must start with test_, so that pytest can find it.

Running your tests

  • Easy way: open your test file and press Run. The bottom of the file starts pytest for you.

  • Programmer way: Tools > Open system shell…, type python -m pytest starter.py -v and press Return (if it says “command not found”, use python3).

starter.py::test_middle_value_stays_the_same PASSED     [ 50%]
starter.py::test_too_small_goes_up_to_low FAILED        [100%]
E       AssertionError: -3 is too small, so it should become 0
E       assert 0 == 5
E        +  where 0 = clamp(-3, 0, 10)
============ 1 failed, 1 passed in 0.03s ============

Read it from the bottom up. The last line is the score. The E lines say what went wrong: clamp gave back 0 but the test expected 5. When a test fails, ask: is the code wrong, or is my expected answer wrong?

Normal and edge cases

A normal case is what usually happens. An edge case is a strange corner: that is where bugs love to hide.

Function Normal case Edge cases
clamp(value, 0, 10) clamp(5, 0, 10) gives 5 too small, too big, exactly 0, exactly 10
best_score(scores) best in the middle empty list, one score, best is first, best is last
encode(msg, shift) "abc" with shift 1 letters near z, spaces and !, shift 0

TipWhy testing matters

In 1999 a spacecraft was lost on its way to Mars because two parts of its software used different units, and no test checked them together. People can only trust apps and games that have been tested. Testing your game is a way of being fair to your players.
