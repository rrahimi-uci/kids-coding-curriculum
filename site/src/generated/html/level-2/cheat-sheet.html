Functions: def and return

def area(width, height):
    """Area of a rectangle."""
    return width * height

big = area(3, 4) + 1   # 13

return hands a value back. print only shows it. Variables made inside a function stay inside (scope).

Files: save and load

try:
    with open("scores.txt") as file:

Testing with pytest

    assert area(3, 4) == 12

Error message decoder

Read the last line first. The line above it shows where.

SyntaxError typo: missing : ) or "
IndentationError spaces at the start of a line
NameError a name is misspelled or not made yet
TypeError mixing types: "5" + 5
IndexError no item at that index (too big)
KeyError that key is not in the dictionary
FileNotFoundError no file with that name in this folder
ValueError int("hello") cannot work

Debugging strategies

1. Read the traceback (last line first). 2. Print-debugging: print("x is", x) to see values. 3. Rubber duck: explain each line out loud.
