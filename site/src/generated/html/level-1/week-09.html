The big idea: labeled boxes

Remember the score variable in Scratch? A variable is a box with a label. You put something in it, and you can use it later.

One equals sign = means put in the box. (Two equals signs == mean something else — see below!)

Asking a question

input asks a question in the Shell and waits. Click in the Shell, type your answer and press Return. But watch out: input always gives back text, even when you type a number.

answer = input("How big should the square be? ")
size = int(answer)

Making choices: if, elif, else

A program can choose what to do. Python checks the rules from the top. The first rule that is true wins, and the others are skipped. else catches everything that is left.

if color_name == "orange":
    color = "#E69F00"
elif color_name == "blue":
    color = "#0072B2"
else:
    print("I do not know that color. I will use black.")
    color = "#000000"

Every if, elif and else line ends with a colon, and the lines under it are pushed in 4 spaces — just like loops.

Comparing

Sign Means Example that is true
== is the same as "blue" == "blue"
!= is not the same as "Blue" != "blue" (Python is picky!)
< is less than 3 < 10
> is more than 25 > 10

Check one box for each question.

Our rule: ask about choices (colors, sizes, numbers), never about who you are. If an app or game asks for personal details, stop and ask a grown-up.
