The big idea: make your own command

In Scratch you made My Blocks. Python has them too! You write def, a name, and the input slots in brackets.

→ 
def flower(x, y, color):
    t.penup()
    t.goto(x, y)
    t.pendown()
    t.color(color)
    ...

Defining writes the recipe. Nothing is drawn yet! Calling uses the recipe. The values in the brackets go into the slots, in order:

TipRemember

Define first (at the top), call later (at the bottom). Calls start at the left edge — not pushed in — or they become part of the recipe.

Exercise10.1: Flower Stamp

Folder: week10/ex-flower-stamp. Run the starter: nothing is drawn! The recipe is there, but nobody calls it.

  1. At the bottom, call it three times: flower(-200, 0), flower(0, 0), flower(200, 0).

  2. Add a third parameter: def flower(x, y, color): and use t.color(color).

  3. Give each call a color: flower(-200, 0, PALETTE[0]), and so on.

Done looks like: three flowers in different colors, each with a yellow middle.

Surprise! The random module

random.randint(1, 6) Like rolling a dice: a whole number from 1 to 6.
random.randint(-350, 350) A random spot from left (-350) to right (350).
random.choice(PALETTE) Like picking a crayon from a bag with your eyes closed.

Put import random at the top of your program, next to import turtle.
