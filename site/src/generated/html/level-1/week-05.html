The big idea

Big jobs, small named parts

A garden picture is a big job. Break it into parts and give each part a name. Then the main plan is short and easy to read.

In Scratch, My Blocks → Make a Block lets you make a pink block with your own name. You put its steps under a define hat. An input is a blank you fill in each time you use the block, like “size”.

Messages

broadcast sends a message to every sprite, like an announcement on a loudspeaker. Only scripts that start with when I receive that exact message run.

Exercise5.1: Shape Machine

Make your own block that can draw any shape.

  1. New project. Add the Pen extension. Set the cat’s Size to 40.

  2. My Blocks → Make a Block. Type polygon. Click Add an input (number or text), type sides. Add another input: length. Click OK.

  3. Build the define script. Drag the sides and length ovals out of the define hat into the slots.

  4. Build the green-flag script with your new pink block. Click the flag!

  5. Add a pentagon: one more block, “polygon 5 70”.

Exercise5.2: Stamp Garden

  1. New project with the Pen extension. Delete the cat. Hover over Choose a Sprite and click the Paint brush. Draw a flower in the middle of the canvas (circles for the center and petals). Name the sprite Flower.

  2. Make two My Blocks: flower with an input size, and grass with no input.

  3. Build the three scripts. For the grass color, click the color circle and set Color 45, Saturation 100, Brightness 62 (see the color-safe paint box).

Done when: each click on the flag grows a new garden: a strip of grass and 12 flowers of different sizes and colors in surprise places.

Exercise5.3: Show Time

Two sprites put on a show by sending messages.

  1. New project. Keep the cat (the Presenter). Add a Dancer: any sprite with several costumes, like Ballerina.

  2. To make a message: in a “broadcast” block, click the dropdown → New message, type start show. Make another called finale.

  3. Build the scripts. Click the flag and enjoy the show!

Some people see colors differently. These colors stay different for almost everyone. In Scratch, click a color circle and type the three numbers. And never use color as the only clue: add a shape, a pattern or a word too, and keep text big.
