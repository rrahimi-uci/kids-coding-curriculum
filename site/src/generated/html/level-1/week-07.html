The big idea: blocks become words

In Scratch you snapped blocks together. In Python you type the same ideas as words. The computer still does the lines in order, from top to bottom.

Scratch block Python line
→ the green Run button (or F5)
→ t.forward(100)
→ t.left(90)
→ print("Hello!")

Meet Thonny

Thonny is the app where we write Python. It has three important parts.

TipWhere did my turtle go?

The turtle window sometimes hides behind Thonny. Click the Python icon in the Dock at the bottom of the screen.

Every turtle program has the same shape

import turtle            # 1. get the turtle toolbox
t = turtle.Turtle()      # 2. make a turtle and call it t
t.forward(100)           # 3. your drawing commands go here
t.left(90)
turtle.done()            # 4. keep the window open at the end

Lines that start with # are comments. Python skips them. They are notes for people.

Reading a red error message

When Python is confused, it stops and shows red text in the Shell. Don’t panic — it is a clue!

Traceback (most recent call last):
  File "starter.py", line 12, in <module>
    Print("Typo hunt: fixed!")
NameError: name 'Print' is not defined

  • line 12 tells you where to look.

  • The last line tells you what confused Python: it does not know the word Print.
