The big idea

Events are doorbells. A script that starts with a yellow Events hat block waits quietly. When its doorbell rings (the flag is clicked, a key is pressed, the sprite is clicked), it runs.

Conditionals ask a yes/no question. An if block runs the blocks inside it only when the answer is “yes”. An if-else block has two mouths: “yes” blocks and “no” blocks. Exactly one of them runs.

Keep checking! An if checks only once, when it runs. To keep watching, put it inside forever, like a goalkeeper who never stops watching the ball.

Exercise3.1: Arrow-Key Explorer

Make a sprite move with the arrow keys. Each key is its own doorbell.

  1. New project. From Events, drag four “when space key pressed” blocks. Click each dropdown and choose right arrow, left arrow, up arrow and down arrow.

  2. Under each, snap a Motion block: “change x by 10” (right), “change x by −10” (left), “change y by 10” (up), “change y by −10” (down).

  3. Click the stage once, then press the arrow keys. Save as explorer: you need it for 3.3!
