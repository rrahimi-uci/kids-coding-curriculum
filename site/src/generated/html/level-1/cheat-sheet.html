Python turtle in Thonny

Getting started

import turtle Load the turtle tools.
t = turtle.Turtle() Make a turtle: t.
screen = turtle.Screen() The window.
turtle.done() Keep it open (last line).

Moving and drawing

t.forward(100) Walk 100 steps.
t.back(50) Walk backwards.
t.left(90) Turn left 90 degrees.
t.right(90) Turn right 90 degrees.
t.penup() Pen up: move, no line.
t.pendown() Pen down: draw again.
t.goto(x, y) Jump to (x,y)(x, y).
t.setheading(90) Face up (0 = right).
t.circle(50) Circle, radius 50.
t.dot(20, YELLOW) A filled dot.
t.write("Hi!") Write on the picture.

Colors and style

t.color("#0072B2") Pen and fill color.
t.color(BLACK, ORANGE) Lines, then fill.
t.begin_fill() Start coloring in…
t.end_fill() … fill it now!
t.pensize(3) Thicker lines.
t.speed(0) Fastest drawing.
t.hideturtle() Hide the arrow.
screen.bgcolor(BLACK) Background color.

Loops, choices and functions

for i in range(4):   # repeat 4 times
    t.forward(100)   # inside the loop
    t.left(90)

if n > 10:
    print("Lots!")
elif n == 10:
    print("Exactly ten")
else:
    print("A few")

def square(size):    # make a command
    for i in range(4):
        t.forward(size)
        t.left(90)

square(50)           # use it!

Compare: > bigger, < smaller, == equal, != not equal.

Python is picky!

  • Small letters: print, not Print.

  • A colon : ends every for, if, else, def line.

  • Lines inside are pushed in 4 spaces (Tab).

  • Every ( needs a ); every " needs a partner.

  • Never name a file turtle.py or random.py.
