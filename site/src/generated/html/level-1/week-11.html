The big idea: build, run, check

Big programs are not written in one go. Programmers go round this loop all day long:

It is like building a LEGO set bag by bag: finish bag 1, check it looks like the picture, then open bag 2.

Your milestones

Five small steps (the tiny art show from the demo)

  1. Question: how_many = int(input("How many bubbles? ")). Run.

  2. Function: def bubble(x, y, color): and call it once. Run.

  3. Loop: put the call inside for i in range(how_many):. Run.

  4. Random: random x, y and color. Run twice!

  5. If: if the number is too big, use a smaller one. Run with 500.

TipSave a version

Before a big change, click File → Save as… and add _v2 to the name (fish_party_v2.py). If the change goes wrong, version 1 is still safe.

Exercise11.1: Sprint 1: core drawing works (M2)

Open your project file. Change the example my_shape function into your function: give it a name that says what it draws, and change the drawing. Draw it once at (0, 0). Run. Then call it a second time somewhere else. Run.

Exercise11.2: Partner bug hunt

Swap seats with your partner. Run their program twice: once with a normal answer, once with a strange one (0, a giant number, a word, a capital letter). Write what happened — don’t fix it, just report it!

TipFeedback is a gift

Giving: be kind and specific (“I like how the stars are different sizes”), and make wishes about the program, never the person. Getting: say thank you — then you decide what to change. It is your art.
