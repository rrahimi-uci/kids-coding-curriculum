The big idea

In a video game, a save point lets you try something risky. If it goes wrong, you load the save and try again. Git gives your code save points. Each save point is called a commit. Every commit has a short id (like a1b2c3d) and a message that says what changed. Together the commits make a timeline: the story of your project.

Saving takes two moves, like taking a class photo:

Terminal survival kit

Terminal is a chat window with the computer: type a command, press Return, read the answer.

Type this It means
pwd Where am I? (print working directory)
ls List the files in this folder.
cd git-quest Go into the folder git-quest.
cd .. Go up one folder.
Tab Finish a long name for you. Type cd git-q and press Tab.
⟦k⟧↑\uparrow⟦/k⟧ Bring back the last command, so you do not retype it.

The six git commands

Command What it does Game words
git init start a save system in this folder new save file
git status what changed since the last save? pause menu
git add hero_badge.py choose what goes in the next save pack your backpack
git commit -m "Add star" make a save point with a message save the game
git log –oneline list the save points, newest first load-game menu
git diff show exactly what changed spot the difference
git restore hero_badge.py throw away unsaved changes reload last save

TipStuck in a strange screen?

If you typed git commit without -m, git opens an editor called Vim. Press Esc, type :q! and press Return. Then try again with -m "your message".

Good commit messages

A good message finishes the sentence “This commit will …”. Start with a verb, keep it short (50 letters or fewer) and say what changed.

 Not helpful  Helpful
stuff Add jump to hero
update Make star twice as big
fixed it Fix score going below zero

TipSafety: history remembers everything

Git writes your user.name and user.email into every commit, forever. Use a nickname and an @example.com email. Never commit passwords, real names, addresses or photos of people. Deleting a file later does not delete it from the history.
