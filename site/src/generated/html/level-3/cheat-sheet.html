Classes and objects

class Pet:                # blueprint
    def __init__(self, name):
        self.name = name  # attribute
        self.energy = 5

    def play(self):       # method
        self.energy -= 2
        return self.name + " had fun!"

mo = Pet("Mo")            # an object
print(mo.play(), mo.energy)

Attributes = what it has. Methods = what it does. self means “this object”; every method needs it first.

Inheritance (IS a), composition (HAS a)

class Dragon(Pet):        # IS a Pet
    def __init__(self, name):
        super().__init__(name)
        self.fire = 3

    def play(self):       # override
        return "Roar!"

class Zoo:                # HAS pets
    def __init__(self):
        self.pets = [Pet("Mo"),
                     Dragon("Ash")]

    def play_all(self):
        for pet in self.pets:
            print(pet.play())

Searching: how fast is fast?

def binary_search(items, target):
    # items must be SORTED
    low, high = 0, len(items) - 1
    while low <= high:
        mid = (low + high) // 2
        if items[mid] == target:
            return mid    # found it
        elif items[mid] < target:
            low = mid + 1  # right
        else:
            high = mid - 1 # left
    return -1             # not there

Sorting

Selection sort: find the smallest, swap it to the front, repeat with the rest. Bubble sort: swap neighbors in the wrong order; repeat until nothing swaps.

print(sorted([7, 3, 9]))  # [3, 7, 9]

Recursion

A function that calls itself on a smaller problem. It needs a base case to stop, or Python gives a RecursionError.

def tree(t, length):
    if length < 10:       # base case
        return
    t.forward(length)
    t.left(30)
    tree(t, length * 0.7) # smaller
    t.right(60)
    tree(t, length * 0.7)
    t.left(30)
    t.backward(length)    # go back

Grids (2D lists)

grid = [["."] * 5 for r in range(3)]
grid[1][2] = "#"          # [row][col]
for row in grid:
    print("".join(row))

Neighbors of (r, c): up (r-1, c), down (r+1, c), left (r, c-1), right (r, c+1).

BFS (shortest path): put the start in a deque. Repeat: popleft() a square, add its unvisited neighbors to the back, remember where each came from.

git: save points (in Terminal)

git init start a repo (once)
git status what changed?
git diff show changed lines
git add game.py choose a file (. = all)
git commit -m "Add X" make a save point
git log –oneline list save points
git restore game.py undo changes not yet committed
pwd where am I?
cd folder go into a folder

Good message: verb + what changed, e.g. "Fix ghost walking through walls". Never commit secrets or real names.
