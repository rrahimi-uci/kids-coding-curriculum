The big idea: the data detective’s pipeline

A data detective always works in the same order. Skipping a step gives wrong answers!

1. Read: what is a CSV file?

CSV means comma-separated values: a table saved as plain text. The first line is the header (the column names). Every other line is one row. Here is the start of favorite_games.csv – made-up, anonymous survey answers (a response number, no names):

response,age_group,favorite_game,genre,hours_per_week,stars
1,10-11,Block Craft,building,5,5
2,12-13, block craft ,building,3,4
5,,,,,
7,12-13,Kart Dash,racing,,3

csv.DictReader turns each row into a dictionary: row["favorite_game"] is "Block Craft".

import csv
with open("favorite_games.csv", newline="") as f:
    for row in csv.DictReader(f):
        print(row["favorite_game"], row["stars"])

2. Clean: wash the data first

Every value arrives as text, even numbers: "5", not 5. And people type things in different ways. Spot the mess:

Messy value Problem Clean it with
" block craft " extra spaces, small letters .strip().title() → "Block Craft"
"BLOCK CRAFT" capitals .title() → "Block Craft"
"5" a number stored as text int("5") → 5
"" (hours) missing answer use None, and skip it in averages
5,,,,, empty row skip the whole row

3 and 4. Count and calculate

Counting with a dictionary is like a tally chart. The first time you see a game, counts.get(game, 0) gives 0:

counts = {}
for row in rows:
    game = row["favorite_game"]
    counts[game] = counts.get(game, 0) + 1
# {"Block Craft": 5, "Kart Dash": 4, ...}

The average (mean) is the total divided by how many: sum(numbers) / len(numbers). Leave out missing answers – counting a blank as 0 would make the average unfairly small.

5. Chart: readable by everyone

A good chart never relies on color alone. Write the name under each bar and the number on top, so someone who sees colors differently can still read it.

SafetyConsent and privacy in surveys

Before collecting data, ask: Did people agree to answer? Can they skip a question? Do I really need this question? Never collect real names, addresses, schools, birthdays or photos. Even without names, answers together can point to one person (“the only 13-year-old in the chess club”). Before sharing data, anonymize it: keep only the columns you need and give each row an ID like R1, R2.
