The big idea: functions that call themselves

Open a Russian doll and you find a smaller doll. Open that one: an even smaller doll. You keep doing the same job until you reach the tiny solid doll – then you stop.

A recursive function works the same way. It has two parts:

  • the base case: the tiny problem you can answer straight away – stop here;

  • the recursive case: do one small step, then call yourself on a smaller problem.

countdown: a recursive function

def countdown(n):
    if n <= 0:            # base case: stop
        print("Liftoff!")
        return
    print(n)              # one small step
    countdown(n - 1)      # the same job on a smaller number

Bug huntNo base case = never-ending dolls

If you forget the base case, the function calls itself forever. Python stops it after about 1000 calls with RecursionError: maximum recursion depth exceeded. When you see that error, look for the base case first. Also check that each call is on a smaller problem (n - 1, not n).

Fractals: pictures made of smaller copies

A fractal is a shape made of smaller copies of itself. A tree is a trunk with two smaller trees on top. Each smaller tree is a trunk with two even smaller trees on top... until the depth reaches 0.

Grids: worlds made of rows

A grid is a list of rows, and each row is a list of cells. You find a cell with grid[row][col]: first go down to the row, then across to the column. Both start at 0.

You can make a grid from strings: grid = [list(row) for row in ["    ", " .T ", " .^ "]]. Change a cell with grid[2][1] = "T". The neighbors of a cell are the cells up, down, left and right of it (watch out for the edges!).

A paint bucket (flood fill) uses recursion on a grid: paint this cell, then ask each neighbor to do the same – but stop at the edge, at walls, and at cells you have already painted. Those are the base cases.
