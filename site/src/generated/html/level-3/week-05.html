Two ways to sort

Selection sort: find the smallest item and swap it to the front. Then find the smallest of the rest and swap it into second place. Repeat.
Bubble sort: walk along the list comparing neighbors. If the left one is bigger, swap them. After each pass the biggest item has “bubbled” to the end.

Python’s own sort

Python can sort for you. The key is a function that says what to sort by:

scores = [("Ada", 120), ("Leo", 95), ("Mei", 150)]

def points_of(entry):
    return entry[1]                  # sort by the number

best_first = sorted(scores, key=points_of, reverse=True)
print(best_first)   # [('Mei', 150), ('Ada', 120), ('Leo', 95)]

sorted makes a new list and leaves the old one alone.

Stacks and queues

A stack is like a pile of plates: you can only take the top one. “Undo” uses a stack: the last thing you did is the first thing undone. A queue is like a lunch line: join at the back, leave from the front. In Python, collections.deque is a fast queue.
