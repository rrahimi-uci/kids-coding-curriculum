The Thonny debugger

A debugger is a slow-motion replay for your code. You can pause on every line and see the value of every variable.

  • Turn on View > Variables. Click an object there to see its attributes.

  • The highlighted line is the one that will run next.

  • Breakpoint: click a line number to put a red dot on it. Press Debug, then Resume: the program runs and pauses at the dot.

A bug-hunting strategy

TipReading an error

Start at the bottom. The last line says what went wrong (TypeError, NameError, IndexError…). The line above it says where: the file and line number.
