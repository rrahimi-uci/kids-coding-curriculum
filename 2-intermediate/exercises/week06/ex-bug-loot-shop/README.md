# Bug Hunt Station 4 - Loot Shop (wrong answers)

**Goal:** find three bugs that do **not** crash - the program just gives
the wrong answer.

1. Work out on paper: for the basket `[12, 5, 30]`,
   what is the total? What is the cheapest item? Can you buy it all with 50 coins?
2. Open `starter.py` and press **Run**. Compare with your paper answers.
3. Rubber duck time: explain `total_price()` line by line to your partner
   (or a toy). Say what each line does **each time round the loop**.
4. Fix one bug at a time, and run after each fix.

**Done looks like:**

```
Total: 47 coins
Cheapest item: 5 coins
With 50 coins you can buy everything!
```

**Check your work:** open `check_my_work.py` and press **Run**.

**Hint for bug 3:** if a function only prints, what does it give back?
