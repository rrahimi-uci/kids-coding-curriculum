## Hint 1: Where to look
Look at the `while n > 0:` line. The loop only stops when `n` is not more than 0. Fill in your trace table and watch what happens to `n` each round.

## Hint 2: Try this
A `while` loop needs something inside it that changes, or it can never end. Follow the code line by line and write down `n` after every round. Does `n` ever get smaller? Which lines inside the loop touch `n`?
