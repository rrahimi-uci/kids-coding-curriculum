# Exercise 1.1 - Hero Card

**Goal:** make a character card for a made-up hero, using f-strings and all
four data types (text, whole numbers, decimal numbers and True/False).

1. Open `starter.py` in Thonny and press **Run** (F5).
2. Type a made-up hero name (never your real name), a power and a level.
3. A red error appears: `TypeError: can only concatenate str (not "int") to str`.
   That is this week's bug hunt! Read the last line of the error, then do **TODO 1**.
4. Do TODO 2 to TODO 5. Run after each one.

**Done looks like:**

```
+------------------------------+
  HERO:         Nova
  Power:        ice beams
  Level:        4
  Next level:   5
  Power points: 40
  Health:       50.0
  Legend?       False
+------------------------------+
```

**Check your work:** open `check_my_work.py` and press **Run**.

**Extra:** add a line for a sidekick or a favorite color. Can you make the
border change length? Try `print("+" + "-" * 30 + "+")`.
