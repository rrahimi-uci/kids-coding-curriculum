## Hint 1: Where to look
Read the short description above each function in `starter.py`. Run the program with a simple input and decide which function does not do what its description promises. Work on just that one.

## Hint 2: Try this
Compare the function with the sentence in its description, word by word. Common bug spots are a comparison like `>` versus `>=`, a missing `return`, and a missing check for a special case. Fix one function, then run the checks again.

## Hint 3: Almost there
Add a `print(...)` of the values inside the broken function, then run it with the input from the message. Ask yourself: what does the description promise for this input, and what do I get instead? Look closely at the boundary numbers, like exactly 50 or 100.
