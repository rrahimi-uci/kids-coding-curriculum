\begin{core}[What comes back? (paper, 3 minutes)]
Write what each call gives back. Write \texttt{None} if it gives back nothing.
\begin{pycode}
def add_three(n):
    return n + 3

def shout(word):
    print(word + "!")
\end{pycode}
\begin{tabular}{@{}ll@{}}
\texttt{add\_three(4)} gives back & \rule{3cm}{0.4pt} \\[6pt]
\texttt{add\_three(add\_three(1))} gives back & \rule{3cm}{0.4pt} \\[6pt]
\texttt{shout("hi")} gives back & \rule{3cm}{0.4pt} \\
\end{tabular}\par
After \texttt{add\_three(4)} has run, the main program does \texttt{print(n)}. What happens, and why?
\answerlines{1}
\end{core}
