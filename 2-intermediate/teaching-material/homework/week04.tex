\begin{challenge}[Count up to a target]
Write a function \texttt{days\_to\_save(goal, per\_day)} that uses a \texttt{while} loop to count how many days of saving
\texttt{per\_day} coins it takes to reach \texttt{goal} coins. For example \texttt{days\_to\_save(50, 12)} is 5. Add it to the bottom
of your Slime Battle file (above \texttt{if \_\_name\_\_ == "\_\_main\_\_":}) and try it in the Shell.
\answerlines{3}
\end{challenge}
