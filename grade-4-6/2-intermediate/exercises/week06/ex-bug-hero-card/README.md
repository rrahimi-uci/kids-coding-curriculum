# Bug Hunt Station 1 - Hero Card (TypeError)

**Goal:** find and fix the bug using the traceback.

1. Open `starter.py` and press **Run**. Red text appears: a **traceback**.
2. Read it from the **bottom up**:
   * The last line says **what** went wrong. Write it down.
   * The lines above say **where**: which line number, in which function.
3. Before you change anything, say out loud (or to a rubber duck) what
   `card_line("Level", 4)` should give back, and what the code really does.
4. Fix the bug. Run again.

**Done looks like:**

```
Hero: Zoe the Brave
Level: 4
Coins: 120
Next level: 5
```

**Check your work:** open `check_my_work.py` and press **Run**.

**Detective notes:** fill in the bug report in your workbook: error name,
line number, what you changed.
