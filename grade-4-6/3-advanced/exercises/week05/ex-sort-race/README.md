# Exercise 5.1 - Sort Race

**Goal:** write bubble sort and compare it with selection sort by counting
swaps.

1. Open `starter.py` in Thonny. Read `selection_sort` - it is done.
2. Finish the `TODO` inside `bubble_sort`.
3. Press **Run**. You should see:

```
Cards:          [7, 3, 9, 1, 5, 3, 8, 2]
Selection sort: [1, 2, 3, 3, 5, 7, 8, 9] (5 swaps)
Bubble sort:    [1, 2, 3, 3, 5, 7, 8, 9] (16 swaps)
Cards are unchanged: [7, 3, 9, 1, 5, 3, 8, 2]
```

**Check your work:** open `check_my_work.py` and press **Run**.

**Extra:** what happens to the swap counts for a list that is already
sorted? Backwards? Try `[8, 7, 6, 5, 4, 3, 2, 1]`.
