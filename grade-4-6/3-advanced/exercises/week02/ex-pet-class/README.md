# Exercise 2.1 - Pet Class

**Goal:** finish the `Pet` class - a blueprint for virtual pets - and make
two pets that each keep their own numbers.

1. Open `starter.py` in Thonny. Read `__init__` and `feed`: they are done.
2. Finish the `TODO`s in `play`, `mood` and `describe`.
3. Press **Run**. Type `p` a few times, then `f`. Watch Pip change while Bo
   stays the same.

**Done looks like:**

```
Pip the dragon feels okay.
Bo the robot cat feels okay.
f = feed Pip, p = play with Pip, q = quit: p
Pip the dragon feels happy. (hunger 6, happiness 7)
Bo the robot cat feels okay. <- Bo did not change: a different object!
```

**Check your work:** open `check_my_work.py` and press **Run**.

**Extra:** add a `nap()` method (happiness +1), or a third pet. Keep it kind:
your pet should never get sick or blame the player.
