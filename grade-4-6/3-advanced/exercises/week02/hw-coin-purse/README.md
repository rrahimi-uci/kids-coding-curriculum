# Homework 2 - Coin Purse

**Goal:** finish a `CoinPurse` class for a game. It must never let the
coins go below zero.

1. Open `starter.py` in Thonny.
2. Finish `add`, `can_afford` and `spend`.
3. Press **Run**. You should see:

```
You have 10 coins
Bought a potion for 5. Left: 5 coins
Not enough coins for a shield (12).
Bought a map for 3. Left: 2 coins
Found 7 coins! Now: 9 coins
```

**Check your work:** open `check_my_work.py` and press **Run**.

**Git practice:** when every check passes, use **File > Save as...** in
Thonny to save a copy named `coin_purse.py` in `Documents/git-quest`. Then
`git add coin_purse.py` and `git commit -m "..."` with a helpful message.
