\answersweek{11}{Project Studio 2}{What good work looks like for workbook chapter 11 and homework 11.}

\section{Exercise 11.1: My five tests}
\begin{answer}[Good work looks like]
Five or more tests that pass, each with a name that says what it checks (\texttt{test\_walls\_block\_the\_player}). They test logic (moving, scoring, saving, searching), not drawing. At least one edge case: a wall or edge, an empty list or file, zero lives, the same item twice. Quick quality check: break one line of the code -- at least one test should fail.
\end{answer}
\begin{answer}[Example: the workbook's \texttt{Player} tests]
All three example tests pass (\texttt{3 passed}). If you delete the line that turns the star back into \texttt{"."}, the third test (eating a star) fails with score 20 instead of 10: the star was eaten twice.
\end{answer}

\section{Exercise 11.2: Playtest and triage}
\begin{answer}[Good work looks like]
Cards describe what happened and what the player expected, without blame. Crashes, \enquote{cannot start} and \enquote{cannot win} are in \emph{Must fix}; confusing controls and unreadable text in \emph{Should fix}; new features in \emph{Nice to have}. At least one must-fix was fixed and committed, ideally with a new test.
\end{answer}

\section{Exercise 11.3: README}
\begin{answer}[Good work looks like]
All six sections present. \enquote{How it works} names the classes and their links, the data structure, the algorithm and the saved file -- matching the project requirements. Credits list a nickname only, and either \enquote{everything made by me} or each borrowed item with its license (CC0 or CC BY with credit).
\end{answer}

\section{Exercise 11.4: Accessibility and usability}
\begin{answer}[Good work looks like]
All boxes checked honestly and one concrete fix named (e.g. \enquote{added letters to the colored tiles}, \enquote{wrote the controls on screen}, \enquote{made the score text bigger}).
\end{answer}

\section{Homework 11}
\begin{answer}[Core, Challenge and Creative]
Core: README committed, one more bug fixed, 5+ passing tests, talk card filled in. Challenge: a new edge-case test with a matching fix and commit. Creative: box art shows a nickname, not a real name, and stays offline.
\end{answer}
