## Hint 1: Where to look
Read the goal again: say hello, walk, meow, say bye. Scratch runs blocks from the top down, so your stack should follow that same order. Look at the block categories on the left side of the screen.

## Hint 2: Try this
Start with a yellow **Events** block, **when green flag clicked**. Then add blocks one at a time from **Motion**, **Looks** and **Sound**. Click the flag after each new block to see what it does.

## Hint 3: Almost there
You need two **say ( ) for ( ) seconds** blocks from **Looks**, and they are not next to each other. Between them, you need a walking block, **move ( ) steps** from **Motion** (change its number to 100), and a block from **Sound** that plays the meow.
