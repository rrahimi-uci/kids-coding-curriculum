# Teacher reference: Exercise 1.3 - My Sprite Show
> TEACHER ONLY. Keep this file away from students. It is not published on the website.

**Level and week:** Level 1 (Introductory), Week 1  **Kind:** Scratch (offline app)  **Time:** about 8 minutes, plus the last 5 minutes of free build
**Big idea:** Plan the steps on paper first, then build them in the same order.

## The finished project
This exercise is open-ended: every child's show is different. The README example is a sprite called Butterfly, and is one correct answer.

Sprite: Butterfly (any sprite works)
- when green flag clicked
- go to x: -150 y: 0
- say [Welcome to my garden!] for (2) seconds
- glide (2) secs to x: (100) y: (50)
- next costume
- play sound [any sound] until done
- say [The end!] for (2) seconds

Setup: pick any sprite with Choose a Sprite and any backdrop with Choose a Backdrop. The cat may be deleted (right-click it in the sprite pane, then delete). The child writes a 5-step plan on the workbook page before building. Save as `sprite-show`.

## What you should see
- A chosen sprite and a chosen backdrop on the stage.
- On the green flag the sprite starts in the same place every time, then does its steps in the same order as the written plan.
- At least 5 blocks sit under the hat block.
- Speech bubbles stay on screen long enough to read (say ... for 2 seconds).

## Talking points
- "Plan first, build second: your paper plan is the algorithm, the blocks are the program."
- "Read your plan out loud while the show runs. Does each step happen when you said it would?"
- "Why does the first block move the sprite to a start spot?" (Scratch remembers where the sprite stopped last time.)

## Common mistakes and quick fixes
- The plan and the script do not match: read both line by line and fix whichever is wrong.
- The sprite starts somewhere new on each run: add a go to x: y: block directly under the hat block.
- The speech bubble disappears too fast to read: use "say ... for 2 seconds", not plain "say".
- "next costume" shows nothing: some sprites have only one costume. Pick a sprite with several costumes or use a different block.
- The script is on the wrong sprite (for example the deleted or other sprite): click the sprite you want and check the code area.
- Nothing runs: blocks are not snapped under the hat block.
