# Exercise 3.1 – Arrow-Key Explorer

**Goal:** use **events** (key presses) to move a sprite with the arrow keys.
**Tool:** Scratch app (offline). **Work in pairs:** the navigator predicts before each test.

## Build steps

1. Start a new project: **File > New**. Keep the cat or choose any sprite.
2. From **Events**, drag four **when (space) key pressed** blocks into the code area.
3. Click each dropdown and choose **right arrow**, **left arrow**, **up arrow**, **down arrow**.
4. Under each one, snap one **Motion** block (see below).
5. Click the stage once (so Scratch listens to the keyboard), then press the arrow keys.
6. Save as `explorer`. You will use it again in Exercise 3.3.

## The scripts in words

Four separate scripts on the same sprite:

- when right arrow key pressed: change x by 10
- when left arrow key pressed: change x by -10
- when up arrow key pressed: change y by 10
- when down arrow key pressed: change y by -10

(x is left and right; y is up and down.)

## Expected behavior

Each arrow key moves the sprite 10 steps in that direction. Holding a key
down keeps the sprite moving. No green flag is needed: each key is its own
"doorbell".

## Checklist

- [ ] I have four scripts, one for each arrow key.
- [ ] Each key moves the sprite the right way.
- [ ] I can say which key makes y bigger.
- [ ] I saved my project as `explorer`.
