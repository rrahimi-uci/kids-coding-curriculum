## Hint 1: Where to look
The ghost must keep asking one question again and again: is the mouse touching me? Look for a loop in the **Control** category that never stops. The question block with pointy ends is in the **Sensing** category.

## Hint 2: Try this
Use an **if ... then ... else** block from **Control**, and put it inside **forever**. The top part runs when the answer is yes. The **else** part runs when the answer is no. Both parts need a size and a say.

## Hint 3: Almost there
Drop **touching ( mouse-pointer )?** from **Sensing** into the **if** hole. Put **set size to ( ) %** and **say ( )** in each part. The two parts need different numbers. In the **else** part, leave the **say** box empty so the bubble disappears.
