# Exercise 8.2 - Polygon Party

**Goal:** draw three shapes in a row, each with its own `for` loop:
a triangle, a square and a hexagon.

1. Open `starter.py`. The triangle is already done - read its loop.
2. Write a loop for the **square** (4 sides, turn 360 / 4 = ?).
3. Write a loop for the **hexagon** (6 sides, turn 360 / 6 = ?).
   Sides of 60 fit nicely on the screen.
4. Press **Run** (F5) after each shape.

**Done looks like:** an orange triangle, a sky-blue square and a green hexagon,
all closed.

**Check your work:** open `check_my_work.py` and press **Run**.

**Extra:** add a fourth shape below the others: an octagon (8 sides) in
purple `"#CC79A7"`. Lift the pen first, like the other shapes, then try
`t.goto(-50, -200)`.
