## Hint 1: Where to look
Press Run and read the red message in the Shell. It names a line number, so go to that line. The last line of the message tells you what Python did not understand.

## Hint 2: Try this
Python cares about capital letters and exact spelling. Compare the broken line with a similar line that works, letter by letter. Fix only one typo at a time, then press Run again to find the next one.

## Hint 3: Almost there
Each typo is small, like one wrong letter or one capital letter that should be small. Look for the line number in the red message, then check each word in that line, such as `t.____(90)`. Keep going until the red text is gone. Remember, there are 4 typos in all.
